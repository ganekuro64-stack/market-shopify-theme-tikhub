# Vera Market — Shopify Online Store 2.0 Theme

Branded Marketplace Shopify OS 2.0 Theme (Walmart / Best Buy / Amazon UX architecture + custom brand identity).

## Features Included
- **2-Tier Marketplace Header** with live Shopify Predictive Search (`/search/suggest.json`) & Department Quick-Nav Bar
- **Marketplace Bento Hero** + **6 Walmart-Style Illustrated Category Tiles**
- **Pro Stepped Auto-Collage Carousel** with animated progress bars & touch swipe
- **Today's Top Deals**, **Promo Duo Banners**, **Campaign Kit Banner**, & **Illustrated Trust Strip**
- **Collection Page with Sticky Sidebar Filter** (native `collection.filters` + Mobile Slide-over Drawer + Sort By)
- **Flagship Product Page (PDP)** with real Variants, Quantity Bundles, Estimated Delivery Box, 4-Tab Rich Product Description, Sticky ATC
- **Auto-Playing Shoppable Video & UGC Reels** with Fullscreen Lightbox + 1-click Add to Bag
- **YOU MIGHT ALSO LIKE** powered by Shopify Product Recommendations API (`intent=related`)
- **Slide-Out Ajax Cart Drawer** (`/cart/add.js`, `/cart/change.js`, `/cart.js`) with Free Shipping Progress Bar & Frequently Bought Together Upsells

## Connect to Shopify via GitHub (3 Steps)
1. Create a new **private** repository on GitHub (e.g. `vera-market-shopify-theme`).
2. Push this local repository to GitHub:
   ```powershell
   git remote add origin https://github.com/YOUR_USERNAME/vera-market-shopify-theme.git
   git push -u origin main
   ```
3. In **Shopify Admin → Online Store → Themes → Add theme → Connect from GitHub**, authorize GitHub, pick `vera-market-shopify-theme`, and select branch `main`.
